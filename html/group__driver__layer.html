Detailed Description

Contains simple Drivers to specific hardware peripherals and modules for register access.

The Driver layer is the lowest software layer, and is the sole layer permitted to interact directly with the device hardware peripheral/module Special Function Registers (SFRs). They perform single, straightforward register operations without intrinsic validation or complex logic. The responsibility for ensuring correct usage and sequence of these operations lies with the Middleware Layer, which builds upon these basic actions to create more comprehensive functionalities. The Driver Layer is mainly included to allow encapsulation of each register access in a function to not require hardware-in-the-loop (HIL) unit testing of the Middleware layer during development.
