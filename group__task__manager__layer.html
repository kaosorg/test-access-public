Detailed Description

Contains Task Managers that ensure that the correct Task is called at the correct time.

The Task Manager layer orchestrates the high-level operational flow of the program, including interrupt routines. It is responsible for issuing the correct Tasks at the correct time and in the correct order, but does not directly manipulate states or make decisions, as this is the responsibility of the Tasks.

The Task Manager Layer is designed to be able to run a wide selection of application-specific Tasks.
