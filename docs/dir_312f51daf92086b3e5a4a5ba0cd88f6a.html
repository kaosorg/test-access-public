Overview

This repository contains a software component for the Safety Framework project.

For more details, refer to the Project Plan.

See the initial commit for a link to the Detailed Design Component and Unit Test specification Jira Ticket IDs for the component.

Folder Structure

  • src: Contains source code.
  • test: Contains unit test files and support files for testing.
  • submodules: Contains other software components that this component depends on as git submodules.

Development

Development is conducted according to the Developer Guidelines using the VS Code DevContainer feature. All changes must pass the Jenkins pipeline before merging.

When cloning the repository, it is not recommended to initialize the submodules recursively, as they may contain submodules not relevant to this component.
