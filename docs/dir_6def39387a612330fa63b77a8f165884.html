Detailed Description

Safety Framework Software Components Shared Files

Overview

This repository contains shared files for software components in the Safety Framework project and is intended to be added as a git submodule.

For more details, refer to the Project Plan.

See the initial commit for a link to the Detailed Design Component and Unit Test specification Jira Ticket IDs for the component.

Folder Structure

  • doxygen: Contains shared API documentation files (high level descriptions/pages and MISRA compliance documentation) and the Doxyfile used to compile the API documentation (in Jenkins).
  • src: Contains shared header files (type defines/configs)

Development

Development is conducted according to the Developer Guidelines using the VS Code DevContainer feature.
